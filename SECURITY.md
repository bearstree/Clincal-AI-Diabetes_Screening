# Security Policy

Do not report sensitive information in public issues. Until a private reporting address is configured, omit secrets, personal information, health inputs, and exploit details from reports and describe only that a private channel is needed.

This portfolio must never receive real patient identifiers. Raw user health inputs must not be logged. Secrets, tokens, signing keys, and credentials must be stored outside Git in protected environment secret stores.

Only the latest release will receive security fixes during portfolio development.
