# Clinical diabetes screening research tool

An educational FastAPI and web demonstration using a compact logistic model trained on public-use NHANES data. It is not a diagnosis, medical advice, a clinically validated system, or a medical device. Inputs and predictions are not stored by the application. See the in-app safety notice, `/metadata`, and the [source repository model card](https://github.com/bearstree/clinical-ai-portfolio/blob/main/docs/model_card.md) before use.
