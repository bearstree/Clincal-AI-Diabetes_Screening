# Diabetes Screening

A research FastAPI and web demonstration using a compact logistic model trained on public-use NHANES data. It is not a diagnosis, medical advice, a clinically validated system, or a medical device. Inputs and predictions are not stored by the application. Personal, non-commercial use only; commercial use requires prior written approval. See the in-app safety notice, `/metadata`, [license](https://github.com/bearstree/Clincal-AI-Diabetes_Screening/blob/main/LICENSE), and [model card](https://github.com/bearstree/Clincal-AI-Diabetes_Screening/blob/main/docs/model_card.md).
