# Contributing

1. Create a short feature branch from `main`.
2. Keep changes focused and use Conventional Commit messages.
3. Run `ruff check .`, `ruff format --check .`, `mypy src`, and `pytest`.
4. Update tests, documentation, the changelog, and `step_by_step.ipynb` when behavior or workflow changes.
5. Open a pull request and complete the safety, data, licensing, and reproducibility checklist.

Never commit datasets, derived participant rows, model binaries, credentials, health inputs, or signing keys.
