# Privacy notice

This application accepts age, waist circumference, activity status, and diastolic blood pressure solely to calculate a response. The application code does not persist inputs or predictions, use cookies, include analytics, request identity, or create user accounts. The Android app requests only Internet permission and disables Android backup.

The hosting provider may retain network metadata or platform logs under its own policy. Production operators must keep access-body logging disabled, use HTTPS, restrict log access and retention, and publish their actual hosting policy before inviting users. Do not enter names, identifiers, free text, or protected health information. This screening application is not intended for clinical care or emergencies.

Privacy questions and deletion requests may be opened privately through the security contact process in the [public repository](https://github.com/bearstree/Clincal-AI-Diabetes_Screening). Because the application itself has no application database, it cannot retrieve or delete a submitted prediction; a hosting provider may still hold infrastructure logs.
